# Smart Pantry Manager

Java Android application for Mobile App Development 700.

## Requirements implemented
- Pantry CRUD with SQLiteOpenHelper
- RecyclerView with custom adapter
- Seeded recipe collection (20 recipes)
- Strict recipe matching: every required ingredient must exist in the pantry in sufficient quantity
- Basic ingredient-name normalization for singular/plural forms
- Recipe details
- Settings screen with expiring-soon alert preference
- Input validation
- Intents between activities
- Bottom navigation via buttons in the main UI

## Database choice
SQLite was selected because the assignment permits local on-device persistence and it keeps the project self-contained without requiring a server or network connection.

## Run
Open the project root in Android Studio, allow Gradle to sync, then run on an emulator or Android device.

## Important academic submission items
The assignment requires meaningful GitHub commits from the development process, a 5–7 minute narrated video, real screenshots from the running app, and a written report. Those should be produced during your own testing/development rather than fabricated.
